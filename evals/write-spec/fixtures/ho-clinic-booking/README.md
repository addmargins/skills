# ho-clinic-booking

호연의원 진료 예약 서비스의 백엔드 저장소입니다.

호연의원은 수도권에 6개 지점(강남·분당·일산·목동·수원·송도)을 둔 외래 의원 체인으로, 내과·가정의학과·소아청소년과·피부과를 진료합니다. 환자는 호연의원 앱이나 지점 데스크, 대표번호(1588-0000)로 진료를 예약합니다.

## 진료 시간

- 평일 09:00–19:00, 화·목은 21:00까지 야간 진료
- 토요일 09:00–14:00
- 점심시간 13:00–14:00, 일요일·공휴일 휴진

## 지금 예약이 처리되는 방식

- **앱 예약**: 환자 앱(별도 저장소 `hoyeon-patient-app`)에서 본인이나 계정에 등록한 가족의 진료를 예약합니다. 예약금을 결제해야 예약이 확정되고, 내원해서 접수하면 예약금은 그날 수납액에서 차감됩니다.
- **데스크·전화 예약**: 지점 데스크나 대표번호로 받은 예약입니다. 예약금을 받지 않습니다.
- **취소**: 앱에는 취소 기능이 없습니다. 환자가 대표번호로 전화하면 콜센터가 지점 데스크로 넘기고, 데스크 직원이 데스크 콘솔(별도 저장소 `hoyeon-desk-console`)에서 예약을 취소하면서 환불액을 직접 입력합니다.
- **시간 변경**: 데스크에서 기존 예약을 취소하고 데스크 예약을 새로 만듭니다.
- **노쇼**: 예약 서비스가 예약을 NO_SHOW로 표시합니다. 노쇼 예약의 예약금은 원무팀이 매월 말에 모아서 처리합니다.
- **알림 문자**: 진료 전날 리마인더 문자와 취소 안내 문자를 메시지허브로 보냅니다.
