# Intent: 연간 구독 고객이 상담원 없이 중도 해지하고 환불받을 수 없음

작성자: 박지은 (CS 운영팀) · 2026-10-14 · 제품 책임자 검토: 김도윤 (구독 PO)

## Problem
연간 구독 고객이 중도 해지하려면 고객센터에 문의해야 한다. 상담원이 관리자 콘솔에서 환불 금액을 직접 계산해 입력하기 때문에, 문의부터 환불 완료까지 평균 3영업일이 걸리고 계산 오류로 인한 재처리가 월 20건 정도 발생한다(CS 운영팀 9월 집계). 해지 문의는 CS 인입의 18%를 차지한다.

지금 필요한 이유: 법무팀이 전달한 내부 지침 LEG-2026-14(`docs/policies/LEG-2026-14-cancellation-ux.md`)가 2027-01-01부터 "해지는 가입과 같은 채널에서, 가입보다 많지 않은 단계로" 가능해야 한다고 정한다. 지금은 웹에서 가입할 수 있지만 해지는 전화·채팅으로만 된다.

## Desired outcome
- 연간 구독 고객이 웹 계정 화면에서 직접 해지를 신청하고, 해지를 확정하기 전에 환불 예정 금액을 본다.
- 상담원이 개입하지 않아도 환불이 원결제수단으로 처리된다.
- 해지 관련 CS 문의가 지금보다 눈에 띄게 줄어든다(목표치는 아직 정하지 않음).

## Affected users and systems
- 연간 구독 고객(웹 가입자 기준 약 4만 2천 명, 구독 PO 제공 수치).
- CS 상담원: 지금은 해지·환불을 수작업으로 처리한다.
- 재무팀: 환불 정산과 승인.
- 웹 계정 화면(`apps/web/src/pages/account/subscription.tsx`), 관리자 콘솔 환불 화면(`apps/admin/src/pages/refund.tsx`), 결제 서비스(`services/billing/`).

## Scope and constraints
- 범위: 연간 구독의 중도 해지 신청과 부분 환불.
- 범위 밖: 월간 구독, 무료 체험 기간 중 해지, B2B 단체 계약, 모바일 앱(다음 단계).
- 환불 금액 계산은 재무팀 환불 정책 FIN-REF-03(`docs/policies/FIN-REF-03-refund-policy.md`)을 따라야 한다. 이유: 상담원마다 계산이 달라 재처리가 생긴다.
- 상담원이 처리하는 기존 수동 환불 경로는 그대로 유지해야 한다. 이유: 예외 케이스(분쟁, 이중 결제 등)는 계속 상담원이 처리한다.
- 해지 사유를 묻는 것은 괜찮지만 답하지 않아도 해지할 수 있어야 한다.

## Open questions
- 해지하면 즉시 서비스가 중단되는지, 이미 결제한 기간 끝까지 쓸 수 있는지 정하지 않았다.
- 프로모션 할인을 받고 결제한 고객의 환불 기준(정가 기준인지 실결제 기준인지)을 재무팀과 확인해야 한다.
- 마케팅팀이 해지 직전에 리텐션 혜택을 보여주고 싶어 하는데, 이것이 LEG-2026-14와 충돌하는지 모른다.
