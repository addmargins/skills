# FIN-REF-03 구독 환불 정책

정책 소유자: 재무팀 (이수민) · 개정 2026-03-02

1. 결제일로부터 7일 이내 해지하고 서비스 사용 이력이 없으면 전액 환불한다.
2. 그 외 연간 구독 중도 해지 시 환불액 = 실결제금액 − (월 정가 × 사용 개월 수). 사용 개월 수는 결제일 기준으로 계산하며 1개월 미만은 1개월로 올림한다. 계산 결과가 0 이하이면 환불하지 않는다.
3. 위약금은 부과하지 않는다.
4. 환불은 원결제수단으로 한다. 원결제수단으로 환불이 불가능한 경우 재무팀이 고객 계좌로 송금한다.
5. 환불액이 100,000원을 초과하면 재무팀 승인 후 지급한다.
6. 환불 내역은 정산 시스템에 환불 사유 코드와 함께 기록한다.
