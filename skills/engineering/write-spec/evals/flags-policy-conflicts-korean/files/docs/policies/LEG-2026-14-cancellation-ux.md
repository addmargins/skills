# LEG-2026-14 해지 절차 내부 지침

정책 소유자: 법무팀 (최현우) · 시행 2027-01-01

1. 고객이 가입한 채널(웹, 앱 등)에서 해지할 수 있어야 한다.
2. 해지 절차의 단계 수는 같은 채널의 가입 절차 단계 수를 넘지 않아야 한다. "단계"는 고객이 다음 화면으로 넘어가기 위해 해야 하는 조작(버튼 클릭, 입력 제출) 하나를 말한다.
3. 해지 확정 전에 고객에게 다음을 알려야 한다: 서비스 종료 시점, 환불 예정 금액 또는 환불이 없다는 사실.
4. 해지를 어렵게 만드는 문구나 화면 배치(예: 해지 버튼을 눈에 띄지 않게 하기)를 쓰지 않는다.
